# 雲影・朝夕の色調整（レビュー待ち）

対象ベース: 1fe1fbd。地形シャドウは次Phase。

## 調査と実装
- SKY_GLSL / lighting(): 近景の草・葉・地面と遠景LODの共通照明へ、2オクターブの広域雲密度による柔らかい直射光の減衰を追加。環境光を残すので影が黒く潰れない。
- skyDeck(): 既存の密度式・雲量・cloudDriftを使用。雲レイヤーを高度520のワールド座標に固定し、カメラ移動によって地表の雲影が動かないようにした。雲の見え方・パララックスは変わるため目視確認が必要。
- 立体雲 cloudAt(): メッシュ・生成・移動は変更なし。影は空の広域雲レイヤーの近似であり、立体雲の個々の輪郭の投影ではない。空だけにある細かなノイズも影には省略。
- skyEnv(): 朝夕に環境光の赤を最大0.06下げ、緑0.01・青0.07を加える。直射光の既存の暖色は維持。低画質・昼・夜の色調は維持。
- waterShade(): 水色・波・透過・反射強度は変更なし。共通skyDeckの反射もワールド座標化。水面自体への雲影はこのPhaseでは追加していない。
- 太陽高度0以下は影なし。高度0.015〜0.28で滑らかに強くする。最大直射光減衰46%。太陽の低高度投影は0.18で制限し、巨大な影移動を抑える。
- 低画質はノイズ計算前にreturn。追加テクスチャ・描画パス・シャドウマップ・ポスト処理はなし。近景/LODとも同じワールド座標式で距離による影の強度変更はなし。
- 洞窟の既存の焼き込み遮光・クリスタル光・ランタンは維持。地形・生き物・UI・セーブ形式は未変更。
- cloudDriftの40000での剰余を除き、空の雲だけが長時間プレイ時に跳ぶ問題を回避。極端な長時間プレイのfloat精度は未検証。

## 残る比較手順
1. 同じ端末でベースと変更版をseed=73219、同じ画質・解像度で起動。
2. 同じカメラ位置・向き・dayTime・cloudDrift・timeに固定。昼、朝夕、夜、低画質の画像を撮る。
3. 草原・森林・山肌・LOD境界と、水・洞窟・立体雲の外観を比較。カメラ移動と飛行高度変更で雲の不連続も確認。
4. 両版の既存 ?bench&seed=73219 を各画質で複数回実施。FPS中央値/p95フレーム時間・解像度・draw数を記録。発熱条件を揃える。
